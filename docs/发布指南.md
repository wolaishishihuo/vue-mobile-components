# 📦 Vue Mobile Components 发布指南

## 🚀 快速发布（5步走）

有修改需要发布？按以下步骤操作：

### 1️⃣ 提交代码
```bash
git add .
git commit -m "feat: 你的修改描述"
```

### 2️⃣ 记录变更
```bash
# 手动创建changeset文件（推荐）
# 在 .changeset/ 目录下创建 .md 文件，内容如下：
# ---
# "@jname/business": patch  # 选择包名和版本类型
# ---
#
# 修改描述
```

### 3️⃣ 更新版本
```bash
pnpm changeset version
```

### 4️⃣ 构建 & 发布
```bash
pnpm build && pnpm changeset publish
```

### 5️⃣ 提交版本变更
```bash
git add . && git commit -m "chore: version packages"
```

## 📦 包结构

```
packages/
├── core/         # @jname/core - 工具包
├── components/   # @jname/components - 基础组件
├── business/     # @jname/business - 业务组件
├── themes/       # @jname/themes - 主题包
└── playground/   # 开发环境（不发布）
```

## 🏷️ 版本类型

- **patch** (1.0.0 → 1.0.1): 修复bug
- **minor** (1.0.0 → 1.1.0): 新增功能
- **major** (1.0.0 → 2.0.0): 破坏性更改

## 💡 常用命令

```bash
# 开发调试
pnpm dev                    # 启动playground

# 代码检查
pnpm lint                   # 代码格式检查
pnpm typecheck             # 类型检查

# 构建相关
pnpm build                  # 构建所有包

# 发布相关

```

## ⚡ 一键发布脚本

想要更简单？在项目根目录运行：

```bash
# 创建一个快速发布脚本
cat > quick-publish.sh << 'EOF'
#!/bin/bash
echo "🚀 开始发布流程..."

# 1. 检查是否有未提交的修改
if [[ -n $(git status -s) ]]; then
  echo "📝 提交当前修改..."
  git add .
  read -p "请输入提交信息: " commit_msg
  git commit -m "$commit_msg"
fi

# 2. 更新版本号
echo "📊 更新版本号..."
pnpm changeset version

# 3. 构建和发布
echo "🔨 构建所有包..."
pnpm build

echo "📦 发布到npm..."
pnpm changeset publish

# 4. 提交版本变更
echo "💾 提交版本变更..."
git add .
git commit -m "chore: version packages"

echo "✅ 发布完成！"
EOF

chmod +x quick-publish.sh
```

使用：`./quick-publish.sh`

## 🔍 发布验证

发布后验证：

```bash
# 查看包信息
npm view @jname/business

# 查看所有版本
npm view @jname/business versions --json

# 本地测试安装
npm install @jname/business@latest
```

## ⚠️ 注意事项

1. **changeset文件格式**：严格按照yaml格式编写
2. **包名准确**：确保包名正确（@jname/core, @jname/components, @jname/business）
3. **网络权限**：发布需要npm登录和网络访问权限
4. **构建检查**：发布前确保构建成功
5. **依赖关系**：系统会自动处理包间依赖发布顺序
