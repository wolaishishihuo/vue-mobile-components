# 🚀 快速交接指南（5分钟完成）

## ⚡ 一键配置脚本

我们提供了自动化脚本，可以一键完成所有配置更新。

### 使用步骤

```bash
# 1. 进入项目目录
cd vue-mobile-components

# 2. 运行配置脚本
./scripts/update-npm-config.sh

# 3. 按提示输入信息
# - npm scope (例如: your-org)
# - 作者名称 (例如: Your Name)
# - Git 仓库地址 (例如: https://github.com/username/repo.git)

# 4. 确认并等待完成
```

### 脚本会自动完成

- ✅ 创建配置备份
- ✅ 更新所有包的 npm scope
- ✅ 更新作者信息
- ✅ 更新仓库地址
- ✅ 更新 Changeset 配置
- ✅ 更新文档中的示例代码
- ✅ 重新安装依赖

## 📋 配置完成后的步骤

### 1️⃣ 验证配置

```bash
# 运行构建测试
pnpm build

# 类型检查
pnpm typecheck

# 代码检查
pnpm lint
```

### 2️⃣ 登录 NPM

```bash
# 登录你的 npm 账号
npm login

# 验证登录状态
npm whoami
```

### 3️⃣ 创建组织（如果使用组织 scope）

1. 访问：https://www.npmjs.com/org/create
2. 创建组织，名称与你的 scope 一致
3. 选择免费或付费计划

### 4️⃣ 首次发布

```bash
# 发布所有包到 npm
pnpm -r --filter='!playground' publish --access public
```

### 5️⃣ 提交代码

```bash
# 提交所有配置更改
git add .
git commit -m "chore: update npm config for new maintainer"

# 推送到远程仓库
git push
```

## 🎯 后续开发流程

### 日常开发

```bash
# 启动开发环境
pnpm dev

# 构建所有包
pnpm build

# 代码检查
pnpm lint
pnpm typecheck
```

### 版本发布

```bash
# 1. 创建变更记录
pnpm changeset

# 2. 更新版本号
pnpm changeset version

# 3. 构建并发布
pnpm build && pnpm changeset publish

# 4. 提交版本变更
git add . && git commit -m "chore: version packages"
git push
```

## 🔍 常见问题

### Q: 脚本执行失败？

**A**: 检查以下事项：
- 确保已安装 pnpm
- 确保在项目根目录执行
- 检查文件权限：`chmod +x scripts/update-npm-config.sh`

### Q: npm 发布时提示权限错误？

**A**: 解决方案：
```bash
# 1. 确认已登录
npm whoami

# 2. 如果使用组织 scope，检查是否为组织成员
npm org ls @your-scope

# 3. 确保包设置为公开
# 检查 package.json 中有：
# "publishConfig": { "access": "public" }
```

### Q: 包名冲突？

**A**:
- 在 npm 上搜索你的包名，确保唯一
- 修改 scope 名称或包名

### Q: 如何撤销配置？

**A**:
```bash
# 脚本会自动创建备份目录
# 格式：.config-backup-YYYYMMDD-HHMMSS

# 从备份恢复
cp .config-backup-*/package.json .
# ... 恢复其他文件
```
