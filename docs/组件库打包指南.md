# Vue 3 移动端组件库打包指南

将 `src/components` 打包成独立的 npm 依赖包的完整方案。

## 📦 项目结构规划

```
vue-mobile-components/          # 组件库根目录
├── lib/                        # 构建输出目录
├── src/                        # 源码目录
│   ├── components/             # 组件源码 (从项目中复制)
│   │   ├── base/              # 基础组件
│   │   │   ├── Search/
│   │   │   ├── StepsCard/
│   │   │   └── Tab/
│   │   │   ├── ArticleCard/
│   │       ├── MultiUpload/
│   │       ├── Popup/
│   │       ├── RefreshList/
│   │       ├── TableTree/
│   │       └── Upload/
│   ├── styles/                # 全局样式
│   ├── utils/                 # 工具函数
│   ├── types/                 # 类型定义
│   └── index.ts               # 入口文件
├── package.json               # 包配置
├── vite.config.ts             # 构建配置
├── tsconfig.json              # TypeScript 配置
├── README.md                  # 说明文档
└── CHANGELOG.md               # 版本更新日志
```

## 🔧 步骤二：配置构建

### 2.1 Vite 构建配置

```typescript
import { resolve } from 'node:path';
import vue from '@vitejs/plugin-vue';
import vueJsx from '@vitejs/plugin-vue-jsx';
import UnoCSS from 'unocss/vite';
// vite.config.ts
import { defineConfig } from 'vite';
import dts from 'vite-plugin-dts';

export default defineConfig({
  plugins: [
    vue(),
    vueJsx(),
    UnoCSS(),
    dts({
      insertTypesEntry: true,
      include: ['src/**/*'],
      exclude: ['src/**/*.stories.*', 'src/**/*.test.*']
    })
  ],
  resolve: {
    alias: {
      '@': resolve(__dirname, 'src')
    }
  },
  build: {
    lib: {
      entry: resolve(__dirname, 'src/index.ts'),
      name: 'VueMobileComponents',
      formats: ['es', 'umd'],
      fileName: 'index'
    },
    rollupOptions: {
      // 确保外部化处理那些你不想打包进库的依赖
      external: [
        'vue',
        'vant',
        '@vueuse/core',
        '@vant/use',
        'dayjs',
        'lodash-es'
      ],
      output: {
        // 在 UMD 构建模式下为这些外部化的依赖提供一个全局变量
        globals: {
          'vue': 'Vue',
          'vant': 'Vant',
          '@vueuse/core': 'VueUse',
          '@vant/use': 'VantUse',
          'dayjs': 'dayjs',
          'lodash-es': 'lodash'
        }
      }
    },
    cssCodeSplit: false,
    sourcemap: true,
    minify: 'terser',
    terserOptions: {
      compress: {
        drop_console: true,
        drop_debugger: true
      }
    }
  }
});
```

## 📝 步骤三：创建组件库入口

### 3.1 主入口文件

```typescript
// src/index.ts
import type { App } from 'vue';

// 导入所有组件
import Search from './components/base/Search/index.vue';
import StepsCard from './components/base/StepsCard/index.vue';
import Tab from './components/base/Tab/index.vue';
import ArticleCard from './components/core/ArticleCard/index.vue';
import MultiUpload from './components/core/MultiUpload/index.vue';
import Popup from './components/core/Popup/index.vue';
import RefreshList from './components/core/RefreshList/index.vue';
import TableTree from './components/core/TableTree/index.vue';
import Upload from './components/core/Upload/index.vue';

// 导入样式
import './styles/index.less';

// 组件列表
const components = [
  Search,
  StepsCard,
  Tab,
  ArticleCard,
  MultiUpload,
  Popup,
  RefreshList,
  TableTree,
  Upload
];

// 定义安装函数
const install = (app: App) => {
  components.forEach((component) => {
    if (component.name) {
      app.component(component.name, component);
    }
  });
};

// 支持按需导入
export {
  ArticleCard,
  install,
  MultiUpload,
  Popup,
  RefreshList,
  Search,
  StepsCard,
  Tab,
  TableTree,
  Upload
};

// 导出类型
export * from './types';

// 默认导出
export default {
  install,
  version: '1.0.0'
};

// 支持通过 CDN 使用
if (typeof window !== 'undefined' && window.Vue) {
  install(window.Vue);
}
```

### 6.3 按需引入

```typescript

import '@yourorg/vue-mobile-components/lib/style.css';

export default {
  components: {
    RefreshList,
    Upload
  }

```

### 6.4 自动按需引入 (推荐)

使用 `unplugin-vue-components` 实现自动按需引入：

```typescript
// vite.config.ts
import Components from 'unplugin-vue-components/vite';

export default defineConfig({
  plugins: [
    Components({
      resolvers: [
        // 自定义解析器
        (componentName) => {
          if (componentName.startsWith('Vm')) {
            return {
              name: componentName.slice(2),
              from: '@yourorg/vue-mobile-components'
            };
          }
        }
      ]
    })
  ]
});
```

## 📚 最佳实践

### 1. 组件设计原则

- **单一职责**：每个组件只负责一个功能
- **可组合性**：组件可以相互组合使用
- **可配置性**：提供足够的 props 和 slots
- **向后兼容**：版本更新时保持 API 稳定

### 2. API 设计规范

- 使用 TypeScript 严格类型检查
- 提供完整的类型定义
- Props 命名采用 kebab-case
- 事件命名使用动词形式

### 3. 样式隔离

- 使用 scoped 样式避免冲突
- 提供 CSS 变量支持主题定制
- 兼容不同的构建工具

### 4. 文档和示例

- 提供完整的 API 文档
- 包含使用示例和最佳实践
- 维护更新日志

